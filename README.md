## ✨ Core Features

### 🛍️ Grocery List Management
- **Add, edit, and delete** grocery items with details like category and quantity.
- Mark items as **purchased** with a satisfying strikethrough effect.
- **Client-side persistence** using IndexedDB.
- **Seed data** for first-time users.

### 📅 Meal Planning & Recipes (Coming Soon)
- **Drag-and-drop** weekly meal planner.
- **AI-powered recipe suggestions** based on available ingredients.
- Auto-generate a grocery list from a meal plan.

### 📊 Analytics & Data (Coming Soon)
- **Spending tracker** with monthly expense charts.
- **Nutrition tracking** with daily/weekly summaries.
- **Export/import** data as CSV or PDF.

### 📱 Technical Excellence
- **Fully offline-capable** thanks to PWA (Service Worker) technology.
- **Modern, responsive, and accessible UI** built with Tailwind CSS.
- **Dark/Light mode** toggle with `localStorage` persistence.
- **Modular and clean JavaScript architecture** for maintainability.

## 🚀 How to Run Locally

Since this is a client-side application with no build steps, you can run it easily in any modern web browser.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/smart-grocery-app.git
    ```
2.  **Navigate to the directory:**
    ```bash
    cd smart-grocery-app
    ```
3.  **Open `index.html` in your browser:**
    - You can simply double-click the `index.html` file.
    - Or, for a better experience (to avoid potential CORS issues with future API integrations), run a simple local server. If you have Python installed:
      ```bash
      python -m http.server
      ```
      Then open `http://localhost:8000` in your browser.

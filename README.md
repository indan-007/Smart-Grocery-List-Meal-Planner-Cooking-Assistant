# Smart Grocery List, Meal Planner & Cooking Assistant

This is a portfolio-ready, industry-grade web application built with HTML, Tailwind CSS, and modular Vanilla JavaScript. It aims to be a comprehensive tool for managing groceries, planning meals, and assisting with cooking, all while being fully offline-capable and privacy-respecting.

## ✨ Core Features

### 🛍️ Grocery List Management
- **Add, edit, and delete** grocery items with details like category, store, and price.
- Mark items as **purchased** with a satisfying strikethrough.
- Group items automatically by **category or store** for efficient shopping.
- **Spending tracker** to monitor expenses per trip.

### 🤖 AI-Powered Recipe Suggestions
- Get recipe ideas based on the **ingredients you have**.
- Filter recipes by dietary needs: **vegetarian, vegan, keto, etc.**
- Save your favorite recipes for later.

### 📅 Meal Planning Calendar
- **Drag-and-drop** interface to plan your meals for the week.
- **Auto-generate a combined grocery list** from your meal plan.

### 🍲 Advanced Cooking Assistant
- **Step-by-step cooking instructions** with built-in timers.
- **Fullscreen cooking mode** for easy reading in the kitchen.
- Browse recipes by category or search.

### 📊 Analytics & Data
- Visualize your monthly spending with **interactive charts**.
- Track **nutritional information** (calories, macros) for your meals.
- **Export/import** your data as CSV or PDF.

### 📱 Technical Excellence
- **Fully offline-capable** thanks to Progressive Web App (PWA) technology.
- **Modern, responsive, and accessible UI** built with Tailwind CSS.
- **Modular and clean JavaScript architecture** for maintainability.
- **Local-first data storage** using IndexedDB.

## 🚀 How to Run Locally

Since this is a client-side application with no backend or build steps, you can run it easily in any modern web browser.

1.  Clone or download this repository.
2.  Open the `index.html` file directly in your browser (e.g., Chrome, Firefox, Safari).

That's it! All features will work out of the box, including offline functionality after the first visit.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (ES6 Modules)
- **Data Storage:** IndexedDB
- **Charts:** Chart.js
- **PWA:** Service Workers, Manifest.json
- **PDF Export:** jsPDF
